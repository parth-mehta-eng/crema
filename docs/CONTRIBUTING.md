# Contributing / Codex Rules

1. Read `DESIGN.md` before editing UI.
2. Keep this a fun side project. Prefer the smallest solution that works.
3. Do not add infrastructure unless a current feature needs it.
4. Reuse theme tokens from `constants/theme.ts`.
5. Reuse an existing component before creating another.
6. Keep screens focused; extract repeated UI.
7. Never expose Supabase service-role keys in the app.
8. Run `npm run typecheck` and `npm run lint` before considering a task complete.
9. Complete only the active weekend document unless explicitly asked to continue.
10. Update docs when behavior or architecture materially changes.
